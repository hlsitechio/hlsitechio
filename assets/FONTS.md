# Font attribution

## Parisienne

`signature.svg` traces the letterforms of **Parisienne** by Astigmatic
(Google Fonts).

- License: SIL Open Font License 1.1 — free to use, modify and redistribute
- Source: https://github.com/google/fonts/tree/main/ofl/parisienne
- Full license text: https://scripts.sil.org/OFL

The signature is generated by `scripts/build-signature.py`, which rasterises
the text, skeletonizes the glyphs to their centerlines, and emits a
self-contained SMIL-animated SVG. Regenerate with:

    python scripts/build-signature.py

No font binary is redistributed in this repository — only traced vector
outlines, which the OFL permits.
